Embedding

Drop this into any page, before </body>:

<script src="https://example.com/widget/widget.js"
        data-endpoint="https://example.com/api/chat"
        data-accent="#2563eb"
        data-position="bottom-right"
        defer></script>

For a signed-in customer, add a signed identity token so the assistant can see their account: 

data-token="<?= Hostorio\Context\IdentityToken::issue((int) $client->id) ?>"
